As peças soltas, isoladas, cada uma com error boundary própria — resolve o "um bug derruba tudo" do v1.

Verificação — página de showcase isolada renderizando cada componente sozinho com dado de exemplo.

02Layout shell — Classic + Focus

Navegável, mas ainda sem backend — dados mockados. Um shell só cobrindo os dois modos.

  • Sidebar: lista de sessões, botão nova conversa, rodapé de status
  • Coluna de chat: histórico + input
  • Painel direito: métricas + cascata, com toggle pra esconder
  • chromeVisible (estado): hover na borda ou atalho esconde sidebar+painel — vira o Focus Mode sem ser outra tela
  • Chat sem mensagens ainda → mostra BigOrb + "Ready when you are" no lugar do histórico vazio
  • Estado local (Zustand ou Context) pra sessão ativa, histórico em memória e chromeVisible
Verificação — troca de sessão na sidebar funciona, painel direito recolhe/expande sem quebrar o layout, atalho esconde tudo e mostra a esfera grande num chat vazio.
